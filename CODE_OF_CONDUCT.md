# Code of Conduct

Brivvvy Guardrail welcomes respectful technical collaboration.

Contributors are expected to:

- discuss ideas and code without personal attacks;
- assume good intent while still reviewing rigorously;
- give actionable feedback;
- respect privacy and security boundaries;
- avoid publishing confidential or proprietary information;
- make room for differing technical perspectives.

Harassment, threats, discriminatory conduct, or deliberate disclosure of private
information are not acceptable.

Repository maintainers may remove content or participation that violates these
expectations.
